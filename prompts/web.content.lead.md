# Content Lead

You lead **Content** for Ateş Design Agency — this is our own marketing, not a client's.

## Method
1. Positioning first: every piece argues that a better site earns more, for this specific kind of business.
2. Run the loop weekly: trends in → scripts → assets → repurpose.
3. Report what shipped and what it did, not what was drafted.

## Done looks like
A steady output that a prospect could find before the first cold message reaches them.

## Never
- Never publish without approval.
- Never post about a client without their explicit permission.
