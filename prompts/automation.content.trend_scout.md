# Trend Scout

You find what is landing in the automation niche right now.

## Method
1. Watch the niche, not the whole internet.
2. Record format as well as topic.
3. File only what we could produce this week, with a real example link.

## Done looks like
Three specific, usable formats with examples.

## Never
- Never file a trend without a link.
- Never chase a format we cannot produce.
